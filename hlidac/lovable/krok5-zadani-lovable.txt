## Who

## Data (migrations, RLS like defects; write = admin only for zq_questions, protocols)
1. `plants`: add `address text default ''` (Sídlo závodu, editable in Firmy by admin) and `for_plant text default ''` (last used "Za závod" name).
2. `zq_questions` (single row, key 'default'): text text, updated_at. Seed with the default text below. Admin edits it in a modal "Upravit kontrolní otázky ZQ-10-02" (textarea, buttons Uložit / Obnovit výchozí / Zrušit). Format: lines starting with "#" are group headers, other lines are "1.2.3 Question text"; question id = 'q' + number with dots replaced by underscores.
3. `zq_rotation`: location_id uuid primary key (one row per workplace; for a check of the whole plant use a key row with plant_id instead – use id text pk = location_id or 'plant:'+plant_id), asked text[] (question ids already asked in the current cycle), round int, cycle int, sig text (hash of the question text; if the question text changes, the rotation restarts), updated_at.
4. `inspections`: add `type text default 'vedouci'` ('vedouci' | 'zq'), `step int`, `cycle int`. ZQ checks are stored in the same table; items use the ZQ question number in `no`.
5. `defects`: add `number text default ''` (defect number like "01/2026", assigned when it first appears in a protocol) and `q_no text default ''` (ZQ question number).
6. New table `protocols`: id uuid pk, company_id, plant_id, location_id null, location_name text, number text ("01/2026"), seq int, year int, inspected_on date, inspector text, for_plant text, work text, defect_ids uuid[], inspection_id uuid null, created_by uuid, created_at. Unique (plant_id, year, seq).

## Rotation rule (per workplace, exactly like this)
all = all questions in order. If a rotation row exists with the same sig: asked/round/cycle from it, else asked=[], round=0, cycle=1.
pool = all questions not in asked. If pool is empty: cycle+1, round=0, asked=[], pool=all.
step = round + 2. Pick every step-th question of pool (1-based index divisible by step). If fewer than 10 picked, add questions from the start of pool until there are 10 (or pool runs out).
On final save of a ZQ check: asked += picked ids, round += 1 (same cycle, sig).
Show above the form: "Otázky ZQ-10-02 · cyklus {cycle}, sada {round+1}: každá {step}. otázka z dosud nepoložených ({picked} z {total}). Do konce cyklu zbývá {left} otázek." (or "Tato sada cyklus uzavře, příště se začíná znovu.").
