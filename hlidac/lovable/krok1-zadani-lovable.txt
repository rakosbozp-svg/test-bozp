## Weekly view layout (top to bottom)
1. **"Týdenní kontroly BOZP"** board, header hint "týden {ISO week} · {Mon date} – {Sun date}". Short note: "Vedoucí kontroluje své pracoviště minimálně 1× týdně. Co nevyhovuje, se rovnou uloží jako závada." One card per plant (závod): list of its workplaces (locations) with responsible supervisor (editable inline, saves to locations.manager), status "tento týden hotovo dd. m." (green) / "zatím neproběhla" (amber), and a strip of the last 8 weeks (green = done, red hatched = missed, current week outlined). Button on each workplace "Začít kontrolu".
2. **"Rozpracované kontroly"** (only if any): rows with place, answered X z 25, saved date; buttons "Pokračovat" and "Smazat" (confirm).
3. **"Nová kontrola"**: Firma → Závod → Pracoviště (pick existing or "+ Nové pracoviště", which creates the location), then button "Začít kontrolu". Shows info "25 bodů · zodpovědný vedoucí: X · tento týden zatím neproběhla / už proběhla (date)".
4. **"Provedené kontroly"** (last 30): pill "Bez závad" (green) or "N× nevyhovuje" (red), place, date + week, inspector; buttons "Detail" (modal with all answers) and "Záznam (Word)"; admin also delete (confirm, defects stay).

## The check form
- Header: small mono line "Kontrola vedoucího · tý {week} · vedoucí {manager or 'nezadán'}", big title "{plant} › {workplace}". Fields: date (default today, max today), "Kontrolu provedl" (default current user's name).
- Sticky progress bar: "N z 25 otázek", counts ✓/✗/–, button "Zbytek označit jako Vyhovuje".
- Questions grouped by group (dark header bar per group). Each question: number + text, and a 3-part segmented answer "Vyhovuje | Nevyhovuje | Netýká se" (active Vyhovuje = soft green, Nevyhovuje = solid red with white text, Netýká se = grey).
- When "Nevyhovuje": the row turns light red and expands: "Co nevyhovuje" (textarea, placeholder "Když nevyplníš: {default finding}"), "Opatření" (placeholder "Když nevyplníš: {default measure}"), "Závažnost" segmented Vysoká/Střední/Nízká (default Střední), "Odpovídá" (placeholder "Když nevyplníš: {workplace manager or inspector}"), "Termín nápravy" (default today + 3 / 14 / 30 days by severity Vysoká/Střední/Nízká; changes when severity changes unless the user edited it), "Fotky" as 64×54 thumbnails plus a dashed "+" tile (camera on mobile).
- Sticky footer with three buttons: **"Zrušit"** (if anything answered: ask "Opravdu zahodit?" first; discards unsaved changes, an earlier saved draft stays), **"Uložit na později"** (uploads photos, saves/updates inspection_drafts row, returns to the weekly view, toast "Kontrola uložena na později"), **"Uložit kontrolu"** (primary; while unanswered questions remain its label is "Zbývá N otázek" and it is disabled; otherwise "Uložit kontrolu a N závad" / "Uložit kontrolu").
- Starting a check on a workplace where the user has a draft automatically continues the draft (message "Pokračuješ v kontrole uložené {date}").
- On final save: for every "Nevyhovuje" create a `defects` row (status open, company/plant/location, description = typed text or default finding, remedial_action = typed or default measure, severity, responsible = typed or workplace manager or inspector, due_date, photos, source 'vedouci', inspection_id); then insert the `inspections` row with items; delete the user's draft for that workplace; toast "Kontrola uložena, N× závada v záložce Závady." or "Kontrola uložena. Bez závad."
